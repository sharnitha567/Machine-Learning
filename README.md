# Student Performance Prediction using Machine Learning

## Overview
This project demonstrates the data preprocessing steps used in a machine learning workflow on a student performance dataset. The notebook prepares the data for model training by cleaning and organizing it.

## Features
- Load the student performance dataset using Pandas.
- Display the first few rows of the dataset.
- View dataset information.
- Check the number of rows and columns.
- Display column names.
- Identify missing values.
- Handle missing values.
- Remove duplicate records.
- Generate statistical summary of the dataset.
- Encode categorical data using LabelEncoder.
- Split the dataset into training and testing sets using `train_test_split()`.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the dataset.
2. Explore the dataset (`head()`, `info()`, `shape`, `columns`).
3. Handle missing values.
4. Remove duplicate records.
5. Encode categorical variables.
6. Split features and target.
7. Perform train-test split.

## Files
- `Ex_1.ipynb` – Jupyter Notebook containing the preprocessing steps.
- `student_performance_updated_1000.csv` – Dataset used for the project.
